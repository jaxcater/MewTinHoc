Flat public directory consumed directly by the web server / GitHub Pages. `site.webmanifest` declares the PWA identity (name, theme colors, standalone display) and references PNG icons under `img/`. `img/StreakLevel/` holds numbered sprite images used by the streak UI; `LoTrinhDayXich/` contains JSON roadmaps (`csRoadmap.json`, `ictRoadmap.json`) referenced at runtime. `404.html` is a client-side SPA router shim that rewrites unknown paths into hash-based routes so GitHub Pages serves the app shell instead of a hard 404.
