Three independent leaf React components under `src/components/` with no shared internal sub-packages:
- `AiExamTab.jsx` is a stateful UI for generating mock exams: it persists the selected track (`tinhoc_selected_track` in `localStorage`) and generated exam payload (`tinhoc_generated_exam` in `sessionStorage`), simulates an AI generation pipeline via `setInterval` steps, and includes a keyword-matched AI Mentor chat. It reads `TRACK_TYPES` from `../data/roadmap` and uses `canvas-confetti` on success.
- `ExamRepoTab.jsx` is a full CRUD viewer/editor for exam documents stored in a Supabase bucket (configured via `EXAM_DOCS_CONFIG`, `listExamDocs`, `uploadExamDocument`, `renameExamDocument`, `deleteExamDocument`, `ensureDocTypeFolder`, `normalizeFolderKey` from `../lib/examDocsStorage`). It resolves document types by matching storage folder names against `DOC_TYPES` aliases, supports drag-and-drop upload, inline rename/delete with two-step confirmation, search, mobile pagination, and an Office365-powered preview modal for `.doc/.docx` files. Admin-only actions are gated through `isCompanyAdmin(user)` from `../lib/roleService`. Uses `framer-motion` for active-tab transitions and respects `useReducedMotion`.
- `StationQuizView.jsx` is a self-contained quiz runner consuming a `quizData` prop shaped as `{ mcq[], tf[] }`; it shuffles questions per version, tracks MCQ and True/False answers in separate maps, grades locally, fires `onSubmitResult` / `onComplete` callbacks, and triggers confetti when accuracy ≥ 80%.

Dependency direction is one-way outward: these components depend on `../lib/*` helpers and `../data/roadmap`, but nothing inside this module imports each other — they are mounted as sibling tabs by a parent router/tab container.
