This leaf module groups the application's top-level view components under `src/components/`, each a self-contained functional React component with its own local state and CSS.

- Navigation entry point: `Navbar.jsx` exports a shared `TABS` constant (`HOME`, `ROADMAP`, `EXAMS`, `AI_EXAM`) consumed by child pages (e.g. `HomeTab.jsx` imports it to call `onNavigateTab(TABS.ROADMAP)`). It owns URL-driven active-tab detection via `react-router-dom`'s `useLocation`/`useNavigate` and renders the horizontal dock plus brand/streak/profile area.
- Authentication entry point: `LoginPage.jsx` handles Google OAuth through Supabase (`supabase.auth.signInWithOAuth`), parses error hashes from the redirect URL, and includes an inline Terms & Privacy modal built from nested sub-components (`TermsPrivacyModal`, `Section`, `TermsContent`, `PrivacyContent`).
- Dashboard entry point: `HomeTab.jsx` is the largest component — a two-column layout combining a hero banner, quick metrics, a knowledge-matrix grid, and a streak card with admin preview/simulation controls. It composes motion primitives from `framer-motion` and reusable motion sub-components under `./motion/*` (`CountUpNumber`, `MasteryBar`, `StreakFlameStage`, etc.), reads roadmap data from `../data/roadmap` and `../data/questions`, and uses role checks from `../lib/roleService.js`.
- Document viewing: `PdfDocumentViewer.jsx` wraps `pdfjs-dist` with a custom worker loaded as a Vite asset (`pdf.worker.min.js?url`), implements mobile single-page vs desktop continuous-scroll modes, IntersectionObserver-based lazy rendering, canvas DPR capping at `MAX_CANVAS_PIXELS = 6_000_000`, and keyboard/page navigation.
- Loading overlay: `LoadingScreen.jsx` renders a full-screen or boxed loader with a WebP cat animation (falls back to GIF on unsupported browsers) and animated progress dots/bar.
- Announcements: `AnnouncementBanner.jsx` fetches active announcements via `../lib/announcementService.js`, separates important ones into a centered modal (with focus trapping, Escape-to-close, body scroll lock) and up to three stacked toast cards, persisting dismissed IDs in browser storage.

Dependency direction is one-way outward: these components import shared libs (`../lib/*`, `../variants`, `../data/*`, `../supabase`, `../assets/*`) but are not imported by other components in this scope; they are mounted by the app router higher up.
