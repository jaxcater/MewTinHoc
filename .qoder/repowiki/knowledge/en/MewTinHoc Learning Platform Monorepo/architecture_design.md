The root `package.json` is the single entry point: `vite dev` boots the frontend while a custom Vite plugin mounts `server/botpressMiddleware.js` on `/api/botpress` and `/MewTinHoc/api/botpress`, letting the frontend talk to Botpress Cloud through the same dev server. The production flow builds the React app via `vite build` (output consumed by `server/server.js`) and deploys static assets under `static_assets/` for GitHub Pages. Shared runtime dependencies (`@botpress/client`, `@supabase/supabase-js`, `framer-motion`, `react-pdf`, `pdfjs-dist`) are declared once at the root so both `frontend_app` and `server` resolve them from the hoisted `node_modules`. The `scripts.exportRoadmaps.js` script bridges the two by generating roadmap data consumed by the frontend.
