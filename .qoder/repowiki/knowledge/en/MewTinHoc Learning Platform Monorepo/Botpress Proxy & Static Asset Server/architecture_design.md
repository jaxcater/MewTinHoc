Single-process Node.js HTTP server (`server.js`) built on the built-in `http` module with no web framework. Request routing is split into two layers: `server.js` handles static file serving from `dist/` (with path-traversal protection via `safeDistPath`) and forwards any `/api/botpress*` URL to `botpressMiddleware`. The middleware (`botpressMiddleware.js`) implements a small Express-style `(req, res, next)` contract — it enforces body size limits (16 KB), parses JSON, sets CORS based on `BOTPRESS_ALLOWED_ORIGIN`, and dispatches to four endpoints: `/status`, `/files`, `/chat`, `/reset`. Business logic lives in `botpressService.js`, which loads secrets from `.env.local` / `.env` at runtime, constructs a Botpress `Client` when tokens are present, signs an HS256 `x-user-key` JWT for authenticated webhook calls, and maintains an in-memory `Map` of user sessions keyed by a cookie-derived `userId`. `securityHeaders.js` is a pure utility applied to every response, setting CSP, HSTS, X-Frame-Options, etc. Dependency direction is one-way: `server.js` → `botpressMiddleware.js` → `botpressService.js`; `securityHeaders.js` is imported by both entry points.
